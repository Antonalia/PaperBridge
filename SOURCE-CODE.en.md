# Complete corresponding source

[简体中文](SOURCE-CODE.md) | **English**

The corresponding source archive is **`paperbridge-1.0.3-source.zip`**. Public distributions provide this archive and `SHA256SUMS.txt` on the same download page as the XPI, free of charge and continuously available. An XPI alone, a license alone or an upstream homepage is not a replacement for this arrangement.

The archive includes plugin and MCP sources, resources, bundled skills in Chinese and English, build and test scripts, original licenses, and source archives for CPython 3.12.14, PyMuPDF/MuPDF 1.28.2, PyInstaller 6.22.3, TOML Kit 0.15.1 and the pinned build dependencies. Project source is also included under `source/` inside the XPI; large dependency source archives live only in `third_party/sources/` inside the matching source ZIP.

Exact upstream URLs, versions, filenames and hashes are recorded in `third_party/source-manifest.json`. Upstream copyrights and licenses remain intact. Source archives for Python's OpenSSL, zlib, libffi, xz and bzip2 components are also provided. Microsoft C++ runtime DLLs are installed separately by the user, not redistributed in the XPI. See [Build instructions](BUILD.en.md).

References: [GNU AGPL section 6](https://www.gnu.org/licenses/agpl-3.0.html), [Corresponding source on different sites](https://www.gnu.org/licenses/gpl-faq.en.html#SourceAndBinaryOnDifferentSites).
