# 重点、公式与教学例子的写法

## 重点解释

一条重点批注应回答：作者说了什么、它为什么是论证关键、机制是什么、哪些证据支持它、适用前提或边界是什么。不要只翻译高亮句，也不要把作者的设想改写成已验证事实。

可按内容需要选择这种短格式，避免给每条批注套长模板：

```markdown
**要点：** 用中文解释原句在整篇论证中的作用。

**机制：** 说明输入、处理过程和输出；保留核心英文术语。

**证据与边界：** 给出原文页码、表格/图或实验条件；尚未证明的部分标成推断。

**教学例子（构造）：** 用具体任务或数值展示这个机制，指出它与论文实际实验的区别。
```

## 每个核心公式的解释

按以下信息覆盖公式，而不是逐字读符号。简单公式可以合并成短段，复杂公式适合表格和分步计算。

1. **原式及定位。** 转写原论文的式子，写出式号、物理页和章节。为便于说明重排、补记定义或提供等价写法时，把它标成“解释用重写”，与原式分开。
2. **符号与数据流。** 每个符号的含义、类型（标量/向量/张量/分布/函数）、维度、来源，以及训练/推理时是否已知。区分随机变量及其取值、条件输入及目标、样本及其潜变量、时间索引及扩散步数。维度只能从正文、附录或可靠结构关系推出；推导出的维度标“由结构推得”，没写且推不出就写“原文未说明”。
3. **直觉与作用。** 它预测、优化或分解的对象是什么；每个关键项改变什么行为；输出如何进入下一步。解释条件独立、近似和省略项的前提。
4. **教学计算例。** 给具体输入，展示至少一条完整的代入/计算或条件采样过程，并给出结果。不能只有“比如机器人拿杯子”这样的比喻。概率模型若不能直接数值计算，可用小的离散分布和明确假设展示采样/分解；高维神经网络可用标量或小向量展示该公式的一部分，并说明简化范围。
5. **边界与常见误读。** 哪些量只是符号而非实现参数、训练与推理有什么区别、模型生成与物理验证有什么区别。注明哪些前提来自论文，哪些是教学假设。

### 符号表例子

| 符号 | 含义与类型 | 维度/取值 | 此阶段是否已知 | 定义依据 |
|---|---|---|---|---|
| $x$ | 目标，向量 | $\mathbb R^d$ | 训练已知，推理待生成 | 论文定义；若 $d$ 未给出则明示 |
| $c$ | 条件，张量或对象 | 原文未说明时保留未知 | 条件给定 | 所在章节与物理页 |
| $f_\theta$ | 参数化函数 | 输入输出按原文核对 | 参数学习得到 | 方法节 |

这张表只是写法示范，不是任何论文的符号定义。

### 一个可核算的损失例子（通用教学示范）

以下式子和数值是教学构造，只有目标论文确实使用这种损失时才映射到其符号，不能作为原论文实验结果：

$$
L=\frac{1}{d}\sum_{i=1}^{d}(\hat y_i-y_i)^2.
$$

设 $y=(0.2,-0.5)$，$\hat y=(0.3,-0.3)$，$d=2$，则残差为 $(0.1,0.2)$，平方项为 $(0.01,0.04)$，因此 $L=(0.01+0.04)/2=0.025$。若原文使用求和而非均值，原式结果为 $0.05$，不要擅自加入 $1/d$。这个小例子只演示损失计算，没有模拟模型训练或实验精度。

## 易错点

- 一个符号在不同公式可能重载。例如 $H$ 在某处可指历史条件，在另一处可指预测 horizon。按各公式的局部定义解释，不把它们混在同一符号表里。
- 保留下标、上标、集合范围和 conditioning bar。例如预测动作序列、单步动作以及历史观测不是同一个变量。不要凭通用世界模型习惯补出论文未定义的状态或奖励。
- 生成模型的 likelihood、denoising loss 和任务成功率是不同量。不能说训练损失降低就证明真实操作成功率提高，除非论文给出对应实验。
- 指标变化写明比较对象与基准。成功率从 40% 到 60% 是增加 20 个百分点，或相对提高 50%；不是“提高 20%”。论文声称的百分比按原文含义核算，无法确定分母则保留说明。
- 实验结果注明任务、数据划分、真实/仿真、评估方式及对照条件。不要把离线 rollout 的视觉一致性当作真实闭环机器人成功。
- 自己推导的条件独立性、维度、算法伪代码、实例数值都标出依据或假设。若公式页面无法辨认，保留疑点和位置，不能给出确定转写。

## Markdown 与批注的分工

Zotero comment 放局部解释与必要例子；独立 Markdown 保存完整的推导、符号表和实验解读。两者引用相同式号与物理页，避免各写出互相冲突的原式。Markdown 的数学源码使用 `$...$`、`$$...$$`；客户端不支持渲染时，源码本身仍是可交付内容。

论文来源可使用搜索返回的 Zotero 条目 URI。精确页链接须基于已核实的 PDF 附件 key 与物理页码；个人库 `u-` 附件 key 可用于 `zotero://open-pdf/library/items/<key>?page=<page>`。标注深链接则调用当前 bridge 的链接工具，尊重对应类型的开关，不手工构造链接绕过关闭的偏好。普通本地 Markdown 不依赖 Obsidian。
